## Opt1 diagnostics — Easier black-screen investigation

- **Detailed playback logs**, enabled/disabled with Kodi's existing debug setting.
- **Clearer HDMI rejection reasons**, plus a local command to collect Kodi, kernel and display information.
- **Bounded error reporting** to avoid repeating the same failure every frame.

Includes both Opt1 rendering optimizations. No change to picture processing or
hardware eligibility; this update diagnoses unsupported output configurations,
it does not claim to fix them.

[How to collect a report](https://github.com/CroqueMr/intel-dv-libreelec/blob/main/docs/DIAGNOSTICS.md).
