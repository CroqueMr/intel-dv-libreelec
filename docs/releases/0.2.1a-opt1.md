# R0.2.1a-opt1

- **Lighter automatic diagnostics:** useful DV and HDMI/kernel details are kept
  in Kodi's normal log, with repeated messages grouped and limited. Global debug
  logging is no longer needed for these details.
- **Broader Standard-DV display compatibility:** player and driver now share
  v0/v1/v2 capability checks and select the matching HDMI signaling.
- **Gentler HDMI recovery:** short-lived failures can recover immediately;
  persistent failures are paced without permanently excluding the display.

Existing FEL corrections and opt1 rendering optimizations are retained. No
shader, picture-quality, subtitle, OSD or normal non-DV playback change is added.
Older HDMI signaling and the reported matrix route still need physical testing;
this release does not claim that every switch/receiver black screen is fixed.
