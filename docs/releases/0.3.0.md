# R0.3.0

- Convert Dolby Vision to HDR10 output with Profile 7 FEL reconstruction and L1-guided tone mapping to a source-derived mastering target.
- Three playback options in Kodi > Settings > Player > Videos, available at Basic level: Standard Dolby Vision (TV-Led), Convert Dolby Vision to HDR10 output, and Disable Dolby Vision support.
- Optional Player information panel with pixel format, bit depth, metadata, output details and GPU render usage. SDR and HDR10 show only relevant fields.
- Lightweight automatic playback diagnostics for frame drops, skips and playback transitions.

Standard DV remains the default. Settings apply to the next playback.

HDR10 conversion uses a 10-bit framebuffer and requires a deep-color HDMI link.
Conversion uses libplacebo, not Dolby VS10. Creative CM2.9/CM4 trims are not
applied. See the validation notes for test coverage.

See [output modes](../OUTPUT-MODES.md) and [validation](../VALIDATION.md).
